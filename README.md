# MAQON Dashboard V1.4 — Automação WhatsApp + IA

Esta versão preserva o dashboard comercial MAQON e acrescenta automação de atendimento via WhatsApp Business Platform com IA.

## Principais recursos

- Dashboard e CRM MAQON.
- Integrações sociais Facebook/Instagram da V1.3.
- Número oficial MAQON atualizado para **(98) 98421-8479**.
- Painel de status da WhatsApp Cloud API e da OpenAI.
- Teste seguro de respostas de IA antes da ativação.
